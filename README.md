\# arty7



Learning FPGA development from first principles using the Digilent Arty A7 board.



\## Overview



This repository documents my journey into FPGA-based digital design.



The goal is to understand how programmable hardware works:

\- designing digital circuits with Verilog/SystemVerilog

\- generating hardware from high-level algorithms

\- synthesizing designs into FPGA logic

\- implementing communication protocols

\- exploring hardware/software interfaces



\## Hardware



Target board:



\- Digilent Arty A7

\- FPGA: Xilinx Artix-7



\## Toolchain



\### RTL Development

\- AMD Vivado

\- Verilog/SystemVerilog

\- Xilinx simulation and synthesis tools



\### Algorithm-to-Hardware Design

\- MATLAB

\- Simulink

\- HDL Coder



MATLAB/Simulink is used to explore:

\- signal processing algorithms

\- DSP pipelines

\- hardware implementation of mathematical models

\- automatic HDL generation
